# Jitendra Sharma — Portfolio (Angular 17)

## Run locally
```bash
npm install
npm start
```
Then open the printed localhost URL (usually http://localhost:4200).

## Build for production
```bash
npm run build
```
Output goes to `dist/jitendra-portfolio-profile`.

## Before you go live
Replace these two placeholder files with your real assets (same filenames, same folder):
- `src/assets/profile.jpg` — your photo
- `src/assets/Jitendra_Sharma_Resume.pdf` — your actual resume PDF

Everything else (content, projects, experience, skills, contact info) is already filled in
from the provided spec and is editable in `src/app/data/*.ts` and each component's `.html`.
